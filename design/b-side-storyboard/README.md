# UNDERGROUND · B 面分镜室

本轮收录 Coola《折页》杭州站和 Jony J《幸会》合肥站。清单按年份或艺人分组，入场手环与章可贴实物照。静态目录独立于 Next.js 应用，正式页面继续使用原来的入口。预览中修改的演出、行程和照片仅在本次打开期间有效。

## 八个画面

| 镜号 | 页面 | 主要动作 |
|---|---|---|
| 01 | 地下入口 | 点粗毛狗 DJ 擦碟，银盘落到唱片架，声音可选。 |
| 02 | 唱片陈列 | 搜索或筛选透明 CD 盒，抽一张打开对应场次。 |
| 03 | 演出详情 | 看 Personal Note 和三个阶段，沿时间线展开行程单。 |
| 04 | 手翻书 | 点「我在这儿」展开现场，白边照片滑出，翻到背面读散场片段。左右换场。 |
| 05 | 新建与编辑 | 填写票务资料、上传封面，预览一张新的唱片内页。 |
| 06 | 时间线编辑 | 在文字与图片之间夹入多张列车票或登机牌。 |
| 07 | 地图记忆 | 选年份和城市，沿站牌找回演出。 |
| 08 | 名人堂与里程碑 | 选艺人或个人纪念章，回到具体的一晚。 |

每页底栏的「本镜说明」列出画面、交互和衔接。支持手机轻扫翻场、方向键翻场及系统减少动态设置。

## 本地打开

在此目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`。

杭州场次日期来自已有《飞蚊症》互动站。合肥日期与场馆来自用户提供的信息。公开分支采用概念封面；现场照片与朋友圈摘录仅用于私有审稿预览。地图署名见 [地图数据说明](MAP_DATA_ATTRIBUTION.md)。
