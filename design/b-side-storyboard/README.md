# UNDERGROUND · B 面分镜室

本轮收录 Coola《折页》杭州站和 Jony J《幸会》合肥站。清单按年份或艺人分组，手环可贴实物照片；入场章按艺人、巡演和可选日期自动生成。静态目录独立于 Next.js 应用，GitHub Pages 首页发布此静态目录，旧版 Next.js 档案保留于 `archive/`。预览中修改的演出、行程和照片仅在本次打开期间有效。

## 八个画面

| 镜号 | 页面 | 主要动作 |
|---|---|---|
| 01 | 地下入口 | 点粗毛狗 DJ 擦碟，银盘落到唱片架，声音可选。 |
| 02 | 唱片陈列 | 搜索或筛选透明 CD 盒，打开独立的专辑内页；演出以带票副的票根呈现。 |
| 03 | 演出详情 | 看 Personal Note 和三个阶段，沿时间线展开行程单。 |
| 04 | 手翻书 | 点「我在这儿」展开现场，白边照片滑出，翻到背面读散场片段。左右换场。 |
| 05 | 新建与编辑 | 填写票务资料、上传封面，预览一张新的唱片内页。 |
| 06 | 时间线编辑 | 在文字与图片之间夹入多张列车票或登机牌。 |
| 07 | 地图记忆 | 选年份和城市，沿站牌找回演出。 |
| 08 | 名人堂与里程碑 | 选艺人或个人纪念章，回到具体的一晚。 |

以上分镜仅为设计参考，正式网站通过唱片架、演出档案、地图记忆和名人堂导航，不显示分镜目录、审稿说明或跨页面翻镜按钮。支持手机轻扫翻场、方向键翻场及系统减少动态设置。

## 本地打开

在此目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`。

杭州场次日期来自已有《飞蚊症》互动站。合肥日期与场馆来自用户提供的信息。合肥场次已收录用户授权公开的朋友圈原文与 20:00—21:30 演出时间；其他时间线节点为示意。真实照片资源使用 art/hefei-stage.webp、art/hefei-group.webp、art/hefei-moments.webp，存在时自动展示；缺失时使用概念封面并隐藏未上传图片。地图署名见 [地图数据说明](MAP_DATA_ATTRIBUTION.md)。

唱片架收录 Coola《飞蚊症》及安全着陆《安全着陆》《二人赚》《安全自救手册》，按艺人分组展示。前两张安全着陆封面分别使用 Apple Music、Spotify 的公开图片地址；《安全自救手册》暂使用用户提供截图的压缩缩略图。专辑版权归原权利人。
